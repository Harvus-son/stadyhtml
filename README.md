# WebStart — HTML, CSS и JavaScript с нуля

Интерактивный учебник по веб-разработке. Структура курса повторяет единый учебный формат PyStart: маршрут по темам, прогресс, отдельная страница каждого урока, теория, примеры, практика и проверка знаний.

## Запуск

1. Скачай или клонируй репозиторий.
2. Открой `index.html` в браузере.
3. Для публикации включи **Settings → Pages → Deploy from a branch → main / (root)**.

Сборка и установка зависимостей не требуются. Lucide Icons и шрифты загружаются через CDN.

## Формат урока

Каждая тема содержит:
- краткое объяснение простыми словами;
- расширенную теорию с важными понятиями;
- аналогию или пример из жизни;
- пример кода с пояснением;
- практические задания от простого к более самостоятельному;
- мини-проект или практический вызов;
- тест с автоматической проверкой ответа;
- песочницу HTML/CSS/JavaScript с изолированным предпросмотром.

## Возможности

- Единая структура с учебником PyStart.
- Боковая навигация по модулям и урокам.
- Поиск по темам и фильтры по статусу прохождения.
- Сохранение прогресса в localStorage.
- Переключение тёмной и светлой темы.
- Копирование примеров кода.
- Редактор с предпросмотром результата внутри изолированного iframe.
- Адаптивный интерфейс для компьютеров, планшетов и телефонов.

## Файлы

- `index.html` — оболочка приложения и стартовая страница.
- `learning.css` — стили, адаптивная сетка и светлая тема.
- `learning.js` — программа курса, теория, примеры, задания, тесты и логика интерфейса.

## Ограничения

Это клиентский учебный проект без серверной части, аккаунтов и синхронизации прогресса между устройствами. Прогресс хранится в браузере на текущем устройстве. Песочница предназначена для небольших учебных HTML/CSS/JS-примеров, а не для публикации сайтов.
